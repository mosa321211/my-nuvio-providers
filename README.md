# 3arabi Nuvio Providers

Arabic media providers ported from CloudStream extensions for Nuvio.

## Add to Nuvio

Paste this manifest URL into Nuvio:

`https://raw.githubusercontent.com/mosa321211/my-nuvio-providers/refs/heads/main/manifest.json`

See [PROGRESS.md](PROGRESS.md) for port status and known provider limitations.
